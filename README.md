# IFOOD-DEMAND-SENTINEL
Projeto pessoal: Plataforma de inteligência espacial para mapeamento de demanda por tipo de culinária em tempo real. Utilizando a indexação hexagonal H3, o dashboard identifica áreas de alto volume de pesquisas para orientar a expansão estratégica de novos parceiros e otimizar a cobertura da rede no ecossistema iFood.
